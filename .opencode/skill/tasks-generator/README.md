# tasks-generator

## Propósito

Descompone una spec y un plan aprobados en tareas pequeñas, cohesivas,
ordenadas por dependencias reales y verificables.

## Uso

Se activa al solicitar un desglose de tareas o manualmente con
`/tasks-generator`. Produce un `tasks.md` sin código de implementación.

## Instalación global

```bash
mkdir -p ~/.config/opencode/skill
cp -R .opencode/skill/tasks-generator ~/.config/opencode/skill/
```

El comportamiento está definido exclusivamente en `SKILL.md`.
