# spec-reviewer

## Propósito

Revisa y clarifica una spec existente antes de planificarla. Es de solo lectura
y produce hallazgos y decisiones pendientes.

## Uso

Se activa al solicitar la revisión de una spec o manualmente con
`/spec-reviewer`.

## Instalación global

```bash
mkdir -p ~/.config/opencode/skill
cp -R .opencode/skill/spec-reviewer ~/.config/opencode/skill/
```

El comportamiento está definido exclusivamente en `SKILL.md`.
