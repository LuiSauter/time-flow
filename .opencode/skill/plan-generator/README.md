# plan-generator

## Propósito

Genera un plan de implementación a partir de una spec existente y aprobada.

## Uso

Se activa al solicitar un plan o manualmente con `/plan-generator`. Produce un
`plan.md` adaptado al proyecto y con trazabilidad de todos los RF.

## Instalación global

```bash
mkdir -p ~/.config/opencode/skill
cp -R .opencode/skill/plan-generator ~/.config/opencode/skill/
```

El comportamiento está definido exclusivamente en `SKILL.md`.
