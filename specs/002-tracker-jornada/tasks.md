# Tareas · 002 Tracker de jornada

- [ ] Duraciones derivadas de marcas absolutas.
- [ ] Persistencia en el navegador y rehidratación tras el montaje.
- [ ] Recalculo al volver a la pestaña.
- [ ] Cronómetro central, badges de estado y botones dinámicos.
- [ ] Métricas del día y lista de segmentos.
- [ ] Registro manual de bloques.
- [ ] Validar bloques manuales (rango inválido y solapes).
- [ ] Sincronizar entre pestañas abiertas.
- [ ] Estados de carga y error al guardar una transición.

## Backend
- [ ] Endpoints de iniciar, pausar, reanudar y finalizar jornada.
- [ ] Endpoint de bloque manual con validación de solapes.
- [ ] Restricción de una jornada abierta por usuario y empresa.

- [ ] Bloque manual inválido y solapado.
